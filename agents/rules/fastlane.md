**Fastlane rules.**

---

`fastlane/README.md` is autogenerated by fastlane on every run.
Never track it.
Add it to `.gitignore` whenever you scaffold a fastlane setup, and if you find it tracked in an existing repo, remove it.
The lane summary it contains is already available via `bundle exec fastlane lanes`.

---

Lane signatures use **keyword arguments**, never the legacy `|options|` hash.

Good:

```ruby
lane :foo do |readonly: true, environment: 'prod'|
  # ...
end
```

Bad:

```ruby
lane :foo do |options|
  readonly = options.fetch(:readonly, true)
  # ...
end
```

The keyword-arg form gives caller-side clarity (`fastlane foo readonly:false`), self-documents required vs optional inputs, and lets Ruby raise on typos instead of silently swallowing them.
